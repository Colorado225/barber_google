# Marketplace hero redesign

## Objective
Completely redesign only the marketplace hero in the existing React application. Use the user-provided local video as an atmospheric full-bleed background and match the supplied screenshot's editorial barbershop direction: left-aligned oversized typography, dark overlay, elegant gold accent, and prominent search action.

## Reference and assets
- Visual reference: `public/assets/aistudio/screenshot-904d8d97-100d-40b2-b80f-84aefad47931_b4cc79c5.png`
- Background video: `public/assets/video/Modern Classics Barbershop 📍Charlotte,NC Elite design for the future of barber industry.mp4`
- Access public media with a correctly URL-encoded `/assets/video/...` source (spaces and emoji must work).
- No external assets, no generated images, and do not move/rename the provided video or screenshot.

## Current app and scope
- Actual page: `src/components/marketplace/MarketplaceHome.tsx`; change the hero section only, preserving all other marketplace behavior and existing intentional worktree modifications.
- Existing live search state: `searchQuery`, `selectedCommune`, and `communes`; keep these connected to the hero controls.
- Existing listing anchor: `#salons-section`; the primary CTA should scroll there and be meaningfully labeled in French (e.g. “Trouver mon salon”).
- Keep all content honest and compatible with the user's no-mocks preference. No fake city/location, salon counts, reviews, payment claims, availability or business metrics. Derive location filters only from real `communes`; do not fabricate filter chips.
- Search should submit/scroll accessibly and support Enter. Empty real data remains an empty marketplace as it already does below.

## Design direction
Premium, cinematic, editorial barber craft. Full-width video behind the hero, visible enough to feel alive but softened by layered charcoal gradients and shadows for strong text contrast. The screenshot's stronger, left-anchored headline and clear button should guide composition. Use existing ink/charcoal and antique-brass palette, serif italic accent for one short phrase, compact uppercase eyebrow, controlled typography, spacious but useful search panel. Desktop should feel immersive; mobile should be compact and readable with video cropped intentionally.

## Functionality and accessibility
- Video should be muted, looped, inline, autoplay where allowed, with metadata preload; pause or avoid motion when `prefers-reduced-motion: reduce`. Keep a dark CSS fallback if video cannot play.
- Decorative video must be hidden from assistive technology; avoid adding controls or sound.
- Include a dark overlay and/or bottom gradient to keep readable contrast.
- Preserve the controlled salon/service text query and real commune selector. Add labels for search/filter, visible focus states, and a button type.
- Hero CTA scrolls smoothly to the existing results list; honor reduced-motion preferences.
- No placeholder claims; choose neutral copy about exploring available salons and booking.

## Validation
Run typecheck, lint, production build, and the focused marketplace/onboarding tests. If local browser preview is blocked by sandbox socket policy, do not bypass; report that visual browser verification could not run.
